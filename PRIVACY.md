# Loadout Privacy Policy

Effective date: August 31, 2026

Loadout is an open-source, skills-only plugin that inspects project files available in the active
ChatGPT or coding-agent session to recommend compatible MCP servers, hooks, and skills.

## Data handled by Loadout

Loadout does not operate a hosted service and does not send project contents, prompts, credentials,
or usage data to the Loadout developer. Loadout does not include analytics, advertising, tracking,
or a developer-controlled account system.

Project files are read and any approved configuration changes are written through the host product.
That processing is governed by the host product's terms, privacy policy, permissions, and workspace
controls.

## Third-party tools

Loadout can recommend configuration for third-party MCP servers, plugins, and services. Nothing is
connected automatically. Before a selected third-party tool is configured, Loadout identifies known
authentication requirements and asks for confirmation before writing project configuration.

If a user installs or connects a third-party tool, that provider may process data under its own terms
and privacy policy. Users should review those policies before enabling the tool and should never place
credentials in source control.

## Retention and deletion

Because the Loadout developer does not receive or store user data, there is no developer-controlled
user data to retain or delete. Users can remove configuration written in their own project or uninstall
the plugin through their host product.

## Changes and contact

Material changes will be published in this repository with an updated effective date. Privacy questions
can be filed through [Loadout support](https://github.com/sukoji/loadout/issues).
