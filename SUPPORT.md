# Loadout Support

Use [GitHub Issues](https://github.com/sukoji/loadout/issues) for bug reports, compatibility problems,
privacy questions, and feature requests.

Before opening an issue:

1. Remove API keys, tokens, passwords, private repository content, and local endpoint details.
2. Run `npx claude-loadout doctor` when the CLI is available.
3. Include the Loadout version, host product, operating system, expected behavior, and a minimal redacted
   reproduction.

Security-sensitive reports should not include exploit details or secrets in a public issue. Open a minimal
issue asking for a private reporting channel.
